# Dual-Network Harness Distillation 阶段成果

本阶段已真实跑通 GSM8K、seed=42 的五组 Trace Rewriting 实验链路：官方 trace 输入 → Student LoRA/KD → evaluation。

- NN1：对训练样本计算 utility 权重，用于数据筛选/weighted loss。
- NN2：基于模型输出、置信度、一致性和 LoRA 特征，判断能力掌握程度。
- Harness：通过数据隔离 gate 串联 NN1 → LoRA/KD → NN2，并保存 config、checkpoint、预测和 metrics。

本轮结果用于第一阶段工程与风险验证，不代表多 seed 或跨任务结论。
