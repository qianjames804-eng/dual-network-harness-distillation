# Defense integrations

- ADS: the paper page exposes traces but no official code repository was found
  during the 2026-08-10 source check. Do not label an approximation official.
- DOGe: official repository is `https://github.com/UNITES-Lab/DOGe` (MIT).
- Trace Rewriting: official repository is
  `https://github.com/xhOwenMa/trace-rewriting`; it includes pre-generated
  GSM8K/MATH traces, but its paper-faithful run requires much larger hardware.

Integrations remain gated until B0/B1 and the NN1/NN2 stages pass.
